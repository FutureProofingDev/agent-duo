Add /agent-duo slash command for Claude Code and Codex

Runs the whole loop from inside one agent: resolves the peer terminal, launches
the reviewer there with an inlined filled template, then adopts the planner role
in the current terminal. Still Orca-only, since it drives a second terminal, but
no shell wrapper needed.

- commands/ holds the two command shells (agent-duo, agent-duo-review)
- templates/ holds planner/reviewer bodies extracted from prompts/, spliced in
  at build time so nothing is duplicated by hand
- build.sh now also emits dist/claude-commands and dist/codex-prompts
- agent-duo-review is a manual-start fallback if peer resolution is ambiguous
