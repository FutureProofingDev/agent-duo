# Repository guidance

For a request to **install or update Agent Duo**, follow [INSTALL.md](INSTALL.md).
Build and install the complete bundle; copying only the source skill directory
omits required executables. Installation is separate from starting a duo run.

For changes to this repository, see the
[contributing guidance](docs/advanced.md#repository-layout-and-contributing).
Runtime role instructions live in `skill/`; do not adopt a planner or reviewer
role merely because you are installing or editing the repository.
